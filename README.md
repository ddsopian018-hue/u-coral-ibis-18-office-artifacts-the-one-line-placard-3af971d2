A museum placard for the humble office stapler, catalogued as if it were an ancient artifact dug from a lost civilisation: catalogue number, date, forged-steel material, and a donor — the Facilities Department — plus the ritual purpose it supposedly served, binding papyrus to appease the dread god of deadlines. One line, 170 characters, dry curator's voice throughout.

> Cat. No. 0417, c. 2019 CE. Stapler, forged steel, gift of the Facilities Department. Ritual binding device; scribes clamped papyrus to appease the dread god of deadlines.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes the placard line to `output/entry.txt` (pure Python standard library, no network).
